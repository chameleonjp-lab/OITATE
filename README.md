# OITATE

動物の種類ごとの性質を読み取り、群れを適切な囲いへ誘導する3Dアクションパズルゲームの開発リポジトリです。

## 計画・仕様文書

実装時に記述が食い違った場合は、次の順で優先します。

1. [実装契約](docs/IMPLEMENTATION_CONTRACT.md)
   - 敵対的検証後の最上位仕様です。入力、時間、合図、緊張、救助、収容、衝突、得点、補助設定、実装の中止判定を定めます。
2. [状態遷移仕様](docs/STATE_TRANSITION_SPEC.md)
   - 動物、群れ、危険種、囲い、救助を実装するための正式な状態と遷移を定めます。
3. [ゲームデザイン詳細計画書](docs/GAME_DESIGN_MASTER_PLAN.md)
   - 面白さ、動物の役割、操作、カメラ、得点、難易度、説明、アクセシビリティ、完成条件の意図を説明します。
4. [実装計画書](docs/IMPLEMENTATION_PLAN.md)
   - 技術選定、システム構成、依存関係、性能、試験、実装工程の基礎計画です。

既存文書の旧記述と正式仕様が食い違う場合は、実装契約と状態遷移仕様を使用します。廃止した旧仕様は、実装契約の「文書の優先順位」と「廃止する旧仕様」に明記しています。
