# OITATE

動物の種類ごとの性質を読み取り、群れを適切な囲いへ誘導する3Dアクションパズルゲームの開発リポジトリです。

## 計画文書

- [実装計画書](docs/IMPLEMENTATION_PLAN.md)
  - 技術選定、システム構成、実装順序、性能、試験の基礎計画です。
- [ゲームデザイン詳細計画書](docs/GAME_DESIGN_MASTER_PLAN.md)
  - ゲーム性、動物の行動、操作、カメラ、得点、難易度、説明、アクセシビリティ、完成条件を具体化した文書です。

ゲーム性、操作、得点、難易度、画面表示、音、演出については、ゲームデザイン詳細計画書を優先します。技術的な実装方法については、実装計画書を優先します。

現在は計画の確認段階です。明示的な実装開始指示があるまで、ゲームコードの実装は開始しません。
