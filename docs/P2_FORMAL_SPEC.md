# P2 面白さ試作 正式仕様

- 文書版：1.0
- 文書状態：P2実装の固定仕様・後続回帰の参照先
- 対象節目：プロデューサー統括計画 P2「面白さ試作」
- 実装状態：`main`へマージ済みの基準実装

## 1. 目的と範囲

P2は、主人公の位置による接近圧力だけで、臆病種の反応を読んで一つの囲いへ導く面白さを確認する。対象は次に限る。

- 仮形状の臆病種3体。
- 囲い1つ。
- 接近圧力、予備反応、逃走、全身収容。
- P1の移動、カメラ、入力所有権、60Hz固定更新との接続。
- 入口の同時進入を防ぐ簡易な単一予約。
- 完了後の即時再挑戦。

得点、危険種、群れのまとまり、緊張・混乱、Navmesh、完成素材、公開品質はP2の判定対象外とする。正式な入口予約の進展監視と詰まり復帰はP3で追加する。

## 2. 数値と状態

基準値は`src/game/p2-cowardly-simulation.ts`の`P2_TUNING`および`DEFAULT_P2_PEN`と一致させる。

| 項目 | 正式値 |
|---|---:|
| 判断更新 | 20Hz（0.05秒） |
| 注意距離 | 5.5m |
| 誘導距離 | 3.5m |
| 緊迫距離 | 1.5m |
| 予備反応 | 0.45秒 |
| 歩行時の逃走速度 | 0.9m/s |
| 走行時の圧力倍率 | 1.35 |
| 緊迫時の逃走速度倍率 | 1.15 |
| 圧力解除 | 1秒 |
| 収容確定保持 | 0.35秒 |
| 収容動作速度 | 2.2m/s |
| 収容動作の詰まり監視 | 1秒 |
| 動物間最低距離 | 1.35m |

臆病種の実装状態は`idle`、`anticipating`、`fleeing`、`enteringPen`、`captured`とする。`anticipating`では位置を変えず、`fleeing`では主人公から離れる。`captured`は外部の判断・押し合い・入口予約から除外する。

## 3. 収容と衝突

- 動物の全身が囲いの内側へ入り、0.35秒以上維持した時点で`captured`とする。
- 入口予約は一つの囲いにつき一体だけとし、後続は入口手前で重ならない。
- 柵と入口は動物半径を考慮した連続スイープで処理する。
- 主人公が柵を越えて圧力を伝えたり、入口を物理的に固定したりしてはならない。
- 非有限値または不正な時間差はゲーム状態を進めない。

## 4. 受入条件

自動検査で、型検査、P2シミュレーション単体テスト、ビルド、既存P1回帰が成功すること。面白さの最終判定は`docs/P2_PLAYTEST.md`の初見プレイで行い、自動検査の成功で置き換えない。

P1のiPhone実機確認、P2の初見プレイ、主要ブラウザ・端末の実機確認は本仕様の作成時点で未記録である。

## 5. 変更境界

P2の数値、状態、入口規則を変更する場合は、本書と`docs/P2_IMPLEMENTATION_CONTRACT.md`を同じ作業単位で更新し、P3の正式仕様へ暗黙に持ち込まない。
