# P6 実装契約

## 1. 実装境界

- P6は `src/game/p6-vertical-slice-completion.ts` に得点、助言、称号、端末内記録、設定の純粋な規則を置く。
- P5のシミュレーションへP6固有の得点状態を混ぜない。
- 表示は `?p6=1` でだけ有効にする。
- `?p5=1`、`?p4=1`、通常URLの既存表示を壊さない。
- 1作業1Draft PRを維持し、mainへ直接変更しない。

## 2. 得点の不変条件

- 安全、統率、判断、時間の最大値は、それぞれ40,000、25,000、20,000、15,000。
- 総得点はクリア時だけ4項目の合計とする。
- 失敗は未クリアとし、端末内最高記録を更新しない。
- 救助と危険への曝露は、イベントを一度だけ数える。
- 補助ありの記録を標準記録へ混ぜない。
- 保存できない環境でも、得点計算と再挑戦を停止しない。

## 3. 時間と固定更新

- P5の20Hz判断更新を使う。
- 初回説明と一時停止はP6の操作時間へ含めない。
- 時間評価の暫定基準は300秒、600秒。
- 補助ありの危険種狙い中はP5へ渡す判断時間を0.7倍にする。
- 補助設定の有無は結果と記録へ表示する。

## 4. 表示と入力

- 初回説明、設定、結果はキーボードだけでもフォーカスできる。
- 結果画面には総得点だけでなく、4項目、称号、次回の助言、記録状態を表示する。
- 音や振動を切っても、危険、収容、失敗の情報を文字・色・記号で伝える。
- P5の誘導音・威嚇音ボタンは、P6でも同じ入力の意味を保つ。
- 端末保存を行う設定・記録は、個人情報や通信を含めない。

## 5. 開発用機能

- `__OITATE_P6__` は画面状態確認と再挑戦のために提供する。
- `e2e` は開発版かつ `?p6-e2e=1` のときだけ提供する。
- 本番作成物へE2Eフック名、開発クエリ、テスト用直接状態設定を残さない。
- P6 E2Eは、起動、説明解除、設定表示、結果表示、再挑戦を確認する。

## 6. 未確認の扱い

自動検査が成功しても、P5手動受入、P4手動受入、iPhone実機、主要端末性能、8〜12人の初見テストの代わりにはしない。

- プレイ中に補助モードを変更した場合は、標準と補助ありの記録を混ぜないため、現在の試行を0:00からリセットする。
