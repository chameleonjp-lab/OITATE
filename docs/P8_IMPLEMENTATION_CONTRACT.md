# P8実装契約

## 1. ページ構成

- `public/candidate.html` をViteの`public`配下から静的に配信する。
- CSSは`candidate.css`に分離し、外部フォントや外部CSSを読み込まない。
- すべての画像は`public/media`内の自作SVGを相対参照する。
- ゲーム本体への導線は`./?p7=1`とし、配信先のサブパスでも壊れない相対URLを使う。

## 2. 表示とアクセシビリティ

- 見出しの階層を崩さない。
- 画像には内容を説明する`alt`を付ける。
- 色だけで動物の種類や重要な状態を伝えない。
- キーボード操作でリンクとページ内移動を使えるようにする。
- 画面幅が狭い場合も横スクロールを発生させない。
- 動きのある表現は候補ページへ必須にしない。`prefers-reduced-motion`を尊重する。

## 3. 権利と通信

- Herdy Gerdyの名称、ロゴ、画像、比較画像を候補ページへ掲載しない。
- 外部URLへの必須通信を作らない。
- 個人情報、端末固有識別子、広告識別子、プレイ記録の外部送信を追加しない。
- 直接依存のライセンスは`P8_PRODUCTION_INVENTORY.md`へ記録する。
- 自作SVG、HTML、CSSは外部素材を含まないことを記録する。

## 4. ゲーム回帰

- P8の候補ページ追加で、ゲーム本体のDOM、入力、状態遷移、保存形式を変更しない。
- `?p7=1`の既存E2Eを通過させる。
- 既知の未確認事項は、合格扱いにせずページとPRへ表示する。

## 5. 後続で必須の確認

- 実機スクリーンショット3枚以上。
- 15〜30秒の紹介映像。
- iPhone 17 Pro、iPhone 11 Pro、iPad Pro 2018、PCでの性能・画面・入力確認。
- 公開直前の推移依存を含むライセンス確認。

## 6. 開発時診断

- `src/quality/p8-diagnostics.ts`は、フレーム時間、遅延破棄時間、状態遷移を端末内で一時的に記録する。
- `?p8-check=1`はViteの開発時だけ有効とし、E2E用の状態操作を本番へ公開しない。
- 診断レポートへ個人名、連絡先、端末固有識別子、プレイ記録の外部送信先を含めない。
- 保存ボタンはJSONファイルを端末へダウンロードするだけで、サーバー通信を開始しない。
- P8-Bの診断レポートは実機確認の証拠を補助する。実機での操作、性能、画面、音、振動の確認を自動合格にはしない。

## 7. 公開前監査

- `scripts/audit-public-build.mjs`はNode.js標準機能だけで公開ビルドと依存ツリーを監査する。
- 入口はゲーム本体の`index.html`と公開候補ページの`candidate.html`に固定する。
- HTML、CSS、JavaScriptから相対参照を追跡し、存在しないローカル参照をエラーにする。動的に組み立てるURLは監査対象外として、手動確認へ残す。
- 監査結果は`artifacts/p8-public-audit/report.json`と`report.md`へ出力する。生成物は`.gitignore`へ入れ、CI artifactだけへ保存する。
- gzip換算20MiBを公開前の容量上限として扱う。超過時はCIを失敗させる。
- 依存ツリーのライセンス情報が`UNKNOWN`の場合はCIを失敗させる。
- 監査はネットワーク通信、外部送信、アカウント、ゲーム保存を追加しない。
- 監査成功は、実機性能、読み込み体感、画面、音、入力、画像、映像、公開の合格を意味しない。
