# P4 危険検証版 正式仕様

- 文書版：1.0
- 文書状態：P4実装の範囲・数値・受入条件
- 上位計画：`docs/PRODUCER_MASTER_PLAN.md`のP4
- 対応契約：`docs/P4_IMPLEMENTATION_CONTRACT.md`
- プレイテスト票：`docs/P4_PLAYTEST.md`

## 1. 目的と範囲

P4は、危険種を先に隔離する順序パズルの中心だけを確認する。画面は`?p4=1`で開き、P3の六体群れとは別の決定論シミュレーションを使う。

含めるものは次の通り。

- 危険種1体 `predator-1`。
- 保護対象1体 `victim-1`。
- 危険種専用囲い1つ。
- 危険種の`search`、`chase`、`aim`、`lunge`、`recovery`、`disabled`。
- 通常の威嚇音による主人公優先の追跡。
- 狙い開始から飛びかかりまでの予告。
- 最初の攻撃後の救助待ち、救助成功、救助失敗。
- 主人公が囲い内へ入り、逃げ道から外へ出ることで危険種を隔離する条件。
- 危険種を収容した後の即時再挑戦。

P4には、追従種、六体群れの統合、得点、Navmesh、完成素材、公開品質を含めない。P3の通常画面とP3開発APIは回帰互換のため残す。

## 2. 状態と数値

基準値は`src/game/p4-danger-simulation.ts`の`P4_TUNING`と一致させる。

| 項目 | 正式値 |
|---|---:|
| 判断更新 | 20Hz（0.05秒） |
| 危険種の索敵距離 | 8m |
| 攻撃距離 | 1.25m |
| 狙いの最低予告 | 1.2秒 |
| 飛びかかり時間 | 0.45秒 |
| 攻撃後回復 | 1秒 |
| 威嚇音の主人公優先 | 4秒 |
| 威嚇音の再使用待ち | 3秒 |
| 効果終了後の通常耐性 | 1.75秒 |
| 救助期限 | 3秒 |
| 救助後の再攻撃保護 | 1秒 |
| 救助影響範囲 | 2.25m |
| 危険種収容の内部保持 | 0.6秒 |
| 危険種の通常移動速度 | 1.25m/s |
| 主人公追跡速度 | 1.8m/s |

危険種の攻撃段階は、目的の状態とは別に管理する。威嚇音が`aim`中に届いた場合は`aim`を中断し、`chasePlayer`へ移る。`lunge`開始後は中断しない。

保護対象の生存・収容状態は`active`、`rescuePending`、`captured`、`failureLocked`とする。`rescuePending`中は移動と収容を止め、救助期限を進める。

## 3. 攻撃の正式規則

危険種が対象にできるのは、次の条件をすべて満たす保護対象だけである。

1. `active`である。
2. 再攻撃保護時間が終わっている。
3. 危険種から8m以内にいる。
4. 囲いの柵などで視線が遮られていない。
5. 対象までの移動経路が遮られていない。

`chase`から攻撃距離へ入ると`aim`へ移り、対象の位置へ予告を表示する。1.2秒後に視線・距離・対象状態を再確認し、成立した場合だけ`lunge`を開始する。飛びかかりの接触で、最初の攻撃なら対象を`rescuePending`へ移す。

同じ対象を救助した後、再攻撃保護が終わってからもう一度有効攻撃を受けた場合は、無限救助を許可せず失敗とする。

## 4. 威嚇音と救助

威嚇音を危険種へ届けると、通常耐性中でない限り、危険種は保護対象を解除して主人公を4秒追跡する。威嚇音の継続時間は加算せず、残り時間を4秒へ更新する。

次のいずれかで救助を成功させる。

- 救助中の危険種へ威嚇音を届ける。
- 主人公が危険種から2.25m以内へ入り、危険種が主人公を認識する。

救助成功時は、対象を`active`へ戻し、緊張を55相当へ戻し、1秒の再攻撃保護を付ける。危険種は主人公追跡または攻撃後回復へ移る。救助は1プレイ中に何度も成立させず、救助後の再攻撃は失敗へつなげる。

救助期限3秒を過ぎた場合、または別の保護対象が存在する将来の統合版で別対象が攻撃された場合は、`failureLocked`へ移る。P4の対象は保護対象1体だが、失敗状態と再挑戦は先に実装する。

## 5. 危険種専用囲い

危険種は、次の条件を同じ固定更新で満たした場合に収容済みとなる。

1. 危険種の中心が専用囲いの内部確定範囲へ入る。
2. 危険種の当たり判定全体が囲い内部へ入る。
3. 主人公が囲いの外へ出ている。
4. 保護対象が囲いの閉鎖範囲へ入っていない。
5. 危険種が内部に0.6秒以上留まる。

条件成立時に門の通行禁止と危険種の`disabled`を同じ更新で確定し、索敵・追跡・攻撃を停止する。主人公が囲い内にいる間は収容を確定しない。危険種が全身で内部へ入った後は、判定が終わるまで囲いの内側から外へ抜けない。

## 6. 受入条件

P4の制作上の受入条件は次の通りとする。

- 危険種の狙いを、攻撃前の表示で認識できる。
- 危険種を専用囲いへ入れ、主人公が外へ出ると隔離が確定する。
- 救助成功と救助失敗の原因をプレイ後に説明できる。
- 決定論的な安全手順で5回連続収容できる。
- 壁越し、対象喪失、収容済み対象への攻撃を成立させない。
- 救助期限、威嚇音耐性、飛びかかり中断条件が状態の不整合を起こさない。

自動検査の成功は、初見プレイヤーの理解、5人以上の手動プレイ、iPhone実機性能、P3手動受入の合格を意味しない。これらは`docs/P4_PLAYTEST.md`へ別に記録する。

## 7. 変更境界

危険種の攻撃時間、威嚇音の優先順位、救助期限、収容条件、失敗条件を変更する場合は、本書と`docs/P4_IMPLEMENTATION_CONTRACT.md`を同じ作業単位で更新する。追従種、11体統合、得点、Navmeshを追加する場合は、P4の範囲変更として別の承認対象にする。
