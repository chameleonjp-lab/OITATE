# P7実装契約

## 公開入口

P7は `?p7=1` で有効になる。P7以外では、P5/P6で追加した公開状態とE2Eフックを変更しない。P7の表示は横画面を前提とし、縦画面では既存の向き案内を優先する。

## シミュレーション契約

P7は `P5SimulationScenario` を面ごとに渡して同一シミュレーションを構成する。シナリオは次を定義する。

- 臆病種、追従種、危険種の生成数
- 必須経路（安全・速い）
- 必須イベント（誘導音による追従開始、威嚇音による危険種の受容）

`status = completed` は、すべての生成対象を収容し、危険種が存在する場合は隔離し、必須経路と必須イベントを満たした場合だけ設定する。既定シナリオの必須条件は空であり、P5の既存挙動を維持する。

## 進行 API

画面内の `window.__OITATE_P7__` は診断用の公開口で、次を提供する。

- `getState()`：面、状態、メニュー、結果、保存進行を取得
- `retry()`：現在面を再試行
- `openMenu()`：面選択を表示

`e2e` は開発ビルドかつ `?p7-e2e=1` の場合に限り公開する。本番ビルドには完了リプレイを出さない。

## 保存契約

保存キーは `oitate:p7:progress:v1`。面ごとに標準・補助あり・練習の記録バケットを分ける。旧形式の面単位記録は読み込み時に対応するモードへ移行し、未知の値や破損値は無視して初期状態へ戻す。

## UIと回帰

- 面選択では、練習と1面を初期解放し、クリア後に次面だけを解放する。
- 結果画面では、得点、評価、4項目の内訳、次回助言、面別最高記録を表示する。
- 標準・補助ありの音・振動設定はP6と共通利用する。音・振動を無効にしても進行不能にならない。
- 第4の動物はゲート表示だけを実装し、通常の1.0プレイ対象へは追加しない。
