# P8開発時診断の使い方

P8-Bの診断機能は、端末・表示・性能・再開・保存を確認するときの補助記録です。公開ページ、ランキング、アカウント機能ではありません。

## 起動

開発サーバーを起動し、ゲームを次のURLで開きます。

```text
http://127.0.0.1:4173/?p7=1&p8-check=1
```

画面左上の開発用診断に「P8測定中」が表示されます。一定時間遊ぶか、画面回転・一時停止・再開・再挑戦を確認した後、「診断JSONを保存」を押します。

## 記録する内容

- 画面サイズ、表示倍率、画面の向き、タッチ点数、ブラウザ識別情報。
- フレーム時間の最小、平均、95パーセンタイル、最大、遅いフレーム数。
- 固定更新で意図的に捨てた時間。
- 実際に遊んだ時間、カメラ操作時間、再開が必要になった状態。
- P7の面、収容状態、結果、端末内進行の状態。
- 起動、一時停止、再開、面開始、結果、再挑戦、診断保存などの状態遷移。

ここでいう95パーセンタイルは、記録したフレーム時間を短い順に並べたとき、遅い側から5%を除いた位置の値です。平均だけでは見えにくい一時的な引っかかりを確認するために使います。

## 扱いの境界

診断は開発時の`?p8-check=1`でだけ有効です。本番ビルドや通常の`?p7=1`では保存操作を表示しません。JSONはブラウザ内で作り、外部へ送信しません。

この記録だけでは、iPhone 17 Pro、iPhone 11 Pro、iPad Pro 2018、PCでの実機合格にはできません。実機の操作、音、振動、画面回転、読み込み、性能を別途確認し、確認日、ブラウザ、画面サイズ、結果を`P8_PLAYTEST.md`へ記録します。
