# P1 操作試作 実機確認

この確認は、iPhone Safariでしか確定できない入力と性能を記録するために使う。P1は、コードと自動試験が成功しただけでは次段階へ進めない。

## 確認する操作

1. iPhoneを横向きにして起動し、左側の好きな位置から主人公を歩かせ、深く倒して走らせる。
2. 移動する指を離さず、右側を別の指で左右へ動かす。主人公が意図しない方向へ急に曲がらないことを確認する。
3. 移動しながら「誘導」「威嚇」を順に押す。移動やカメラが止まらず、離した時だけ反応が出ることを確認する。
4. 合図ボタンを押したまま外へ大きく滑らせて離す。反応が取り消されることを確認する。
5. 操作中に縦向きへ回転する。全操作が止まり、横向きへ戻した後も勝手に動かないことを確認する。
6. 操作中に別タブまたはホーム画面へ移り、戻る。「再開する」を押すまで動かないことを確認する。
7. 10分間続け、入力不能、停止、著しい発熱がないか確認する。

## 記録する内容

- 端末、iOS、ブラウザ。
- 診断欄の通常時FPSと、大きく下がったときのFPS。
- 移動・カメラ・合図を同時に使ったとき、入力が失われた回数。
- 縦横回転後と画面復帰後に、入力が残った回数。
- 10分後の停止、入力不能、発熱の有無。
- 診断欄の「手動カメラ」の割合。
- 操作で迷った場所を一つ。

初見3〜5人の確認では、説明を加えず、過半数が30秒以内に移動とカメラを扱えるかを記録する。

## P1の判定

次をすべて満たすまで、P2の動物誘導へ進まない。

- 移動、カメラ、合図を同時に使っても入力が失われない。
- 自動追従によって主人公の進行方向が勝手に変わらない。
- 初見3〜5人の過半数が30秒以内に移動とカメラを扱える。
- iPhone 17 Proで平均55FPS以上を目標に満たす。
- 10分間、停止や入力不能が起きない。
