# P7初見・手動受入チェックリスト

この文書は、P7「1.0内容完成」の実装開始時点での受入項目を固定する。未実施の項目を自動テストの通過だけで完了扱いにしない。

## 実施条件

- 実施者：Sol Highの独立レビュー担当
- 初見参加者：8〜12人を目安に、参加者ごとに記録を分ける
- 実施環境：iPhone横画面、iPad、PC。ブラウザ名・OS・端末を記録する
- 実施モード：標準、補助あり、練習
- 記録：各面の詰まり、誤解した説明、入力競合、音・振動設定、FPS低下、コンソールエラー

## 合否基準

| 指標 | 目標 | 記録方法 |
| --- | --- | --- |
| 操作開始 | 15秒以内 | 起動から最初の移動入力までを計測 |
| 最初の反応理解 | 45〜90秒以内 | 参加者が最初に意図した方向へ動物を動かすまで |
| 初回全体クリア | 12分以内の初見クリア率60〜80%を目標 | 面ごとの開始、クリア、失敗、中断を記録 |
| 失敗理解 | 80%以上 | 失敗後に「次に変える行動」を自由回答で記録 |
| 自発的再挑戦 | 50%以上 | 終了案内なしで再試行した人数を記録 |
| 二回目改善 | 70%以上 | 得点、評価項目、時間のいずれかの改善を記録 |
| 技術的失敗 | 10%未満 | 入力、カメラ、詰まり、復帰、例外を別分類で記録 |

各参加者について、`参加者ID / 端末・OS・ブラウザ / モード / 面 / 開始時刻 / 終了時刻 / 結果 / 得点 / 評価 / 失敗理由 / 次に変える行動 / 技術的指摘` を1行で残す。未実施の場合は空欄ではなく「未実施」と記録する。

## P7初見フロー

- [ ] 初回表示で、練習と1面の違い、残りのロック状態、6面の進行が理解できる
- [ ] 練習で移動と収容の基本を説明なしに試せる
- [ ] 1面で接近距離と位置取りが中心概念として伝わる
- [ ] 2面で誘導音と速い経路の意味が伝わる
- [ ] 3面で危険種を先に隔離する判断が伝わる
- [ ] 4面で合図の副作用と対象選択が伝わる
- [ ] 5面で2経路を使い分ける必要性が伝わる
- [ ] 6面で3種類を同時に管理し、複数解が成立する
- [ ] 必須概念を使わずに面が誤ってクリアにならない
- [ ] 4面で近距離の威嚇音が別の動物へ副作用を起こし、その結果を見て立て直せる
- [ ] 5面で安全経路から速い経路へ誘導を切り替えないと完了しない
- [ ] クリア後の次面解放と、リロード後の復元が成立する
- [ ] 標準・補助あり・練習の記録が混ざらない
- [ ] 音オフ・振動オフでも全情報が画面で確認できる
- [ ] 6面クリア後、第4の動物が「検証候補」として表示され、通常面には追加されない

## 端末・性能

- [ ] iPhone横画面で操作、面選択、結果表示が成立する
- [ ] iPadでレイアウト崩れ、タップ領域不足、スクロール不能がない
- [ ] PCでキーボード・ポインター入力が成立する
- [ ] 面切替と結果表示で長いフレーム停止がない
- [ ] コンソールに未処理例外がない

## 判定

全項目の実施記録と重大指摘の確認が揃うまで、P7を手動受入済み、または1.0公開可能とは判定しない。重大な手戻りがある場合はP7実装を停止し、Sol Extra Highへエスカレーションする。
