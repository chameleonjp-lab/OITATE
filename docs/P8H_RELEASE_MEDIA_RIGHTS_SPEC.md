# P8-H 紹介動画・公開直前権利照合仕様

## 目的

P8-Hは、P8-F/P8-Gの実機確認後に、公開候補版を第三者へ説明・公開できる状態へ近づける工程です。15〜30秒の紹介動画、最終固定版、制作物・依存関係・権利台帳を同じ版へ結び付けます。

この工程の準備を先に進めても、P8-F/P8-Gの実機確認を完了扱いにはしません。

## 前提条件

P8-HをPASSへ進める前に、少なくとも次が必要です。

- P8-FのiPhone 17 Pro主要確認がPASS候補以上
- P8-Gで対象端末の結果が記録されている
- 重大な入力、保存、進行、画面復帰、不正終了が残っていない
- 実機スクリーンショットが固定commit SHAへ結び付いている

## 固定版の扱い

P8-H開始時に「公開候補固定SHA」を1つ決めます。そのSHA以外から取得した動画、スクリーンショット、監査結果を混在させません。

固定後にゲームコード、画像、依存関係、設定、文言を変更した場合は固定を解除し、影響する証拠を再取得します。文書だけの変更でも、公開ページに表示される文言や権利表示へ影響する場合は再照合します。

## 15〜30秒紹介動画

動画は実ゲーム画面を中心にし、次の3要素を短く伝えます。

1. 主人公の立ち位置で臆病種を動かす
2. 誘導音で追従種を導く
3. 威嚇音で危険種の注意を主人公へ向け、安全に収容する

### 動画条件

- 長さ: 15〜30秒
- 横画面
- 実ゲームの固定版から取得
- 開発用デバッグ表示を映さない
- 権利未確認の音声、画像、フォント、ロゴを入れない
- ゲーム内容を誤解させる速度変更、合成、未実装演出を使わない
- 音なしでも内容が分かるよう、必要なら短い字幕を使う
- 字幕はゲーム内に存在しない機能を示唆しない

## 動画の構成目安

| 時間 | 内容 | 伝えること |
|---|---|---|
| 0〜4秒 | 主人公と群れの全景 | 3D群れ誘導ゲームであること |
| 4〜10秒 | 接近圧力 | 立ち位置が操作手段になること |
| 10〜17秒 | 誘導音 | 動物ごとに誘導方法が違うこと |
| 17〜25秒 | 危険種と威嚇音 | 順序と危険管理が必要なこと |
| 25〜30秒 | 囲い・結果またはタイトル | 目的と達成感 |

30秒未満に収まる場合は各場面を短縮します。派手さのために同じ場面を繰り返しません。

## 権利最終照合

公開候補固定SHAに対して、少なくとも次を照合します。

- `package.json`の直接依存
- 実際にインストールされた推移依存
- `p8-public-audit`のライセンス結果
- `docs/P8_PRODUCTION_INVENTORY.md`
- `public/`以下の画像、SVG、CSS、動画
- ゲーム内で使う画像、音、フォント、モデル、テキスト
- 候補ページに表示するゲーム名、説明文、ロゴ相当の表現

ライセンスが不明、権利者不明、出所を説明できない制作物は公開候補から外すか、公開前に根拠を確定します。

## 元作品との距離

Herdy Gerdyのゲーム性を参考にした経緯は残しますが、次を公開物へ持ち込みません。

- 原作の名称、ロゴ、キャラクター名
- 原作の画像、音声、モデル、文章
- 原作固有の地名、物語、ステージ配置の複製
- 原作を公式移植・復刻と誤認させる表現

ルール上の役割を参考にしても、名称、世界観、見た目、文章、素材はOITATE独自のものとして管理します。

## 公開直前の自動証拠

固定SHAに対して、既存の型確認、単体試験、ビルド、ブラウザ試験、公開監査を再実行し、結果を固定SHAへ結び付けます。

最低でも次を記録します。

- source head SHA
- tested merge SHAまたは公開候補SHA
- candidate入口のgzip換算容量
- 依存パッケージ数
- UNKNOWNライセンス数
- browser / preview試験結果
- 実ゲーム画像と紹介動画の対象SHA

## P8-Hの判定

### PASS候補

- 紹介動画が15〜30秒で、固定版の実ゲーム画面から作られている
- 公開物と権利台帳の出所を説明できる
- UNKNOWNまたは未確認権利が公開候補に残っていない
- 動画、スクリーンショット、監査結果が同じ固定版へ結び付く
- P8-F/P8-Gの重大な未解決問題がない

### FAIL

- 動画が別版・開発用状態・未実装演出を混ぜる
- 出所不明素材がある
- 重要な権利表示が欠落する
- 固定版変更後に古い証拠を流用する

### BLOCKED

- 実機証拠が不足し、公開候補固定SHAを決められない
- 動画取得手段がない
- 権利根拠を確認できない制作物が残る

## 次工程

P8-H PASS候補後、P8-Iとして実装へ参加していない別のSol・Highが、固定SHA、正式仕様、P8-F/G/H証拠、既知問題、権利台帳を独立に照合します。

P8-Iの合格は公開の勧告であり、public公開そのものの承認ではありません。
