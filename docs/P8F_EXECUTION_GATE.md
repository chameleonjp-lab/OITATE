# P8-F 実行ゲート

## 現在地

PR #25で、P8-Fの手動受入手順と証拠テンプレートは`main`へマージ済みです。

現時点の判定は **P8-F: NOT TESTED** のままです。手順書を用意したことと、実機・初見確認を実施したことは分けて扱います。

## 次に実行する確認

最初の端末はiPhone 17 Proとし、`docs/P8F_MANUAL_TEST_RUNBOOK.md`の順序で次を一巡します。

1. 横画面で起動し、移動・カメラ・誘導音・威嚇音・取消・同時入力を確認する。
2. P4危険管理で、攻撃予告の認識、危険種の収容、救助理由を確認する。
3. P5統合で、3種類の違い、11体進行、複数解、得点理解を確認する。
4. P6で初回説明、結果画面、再挑戦、補助設定を確認する。
5. P7で6面進行、保存、再読み込み、面別条件を確認する。
6. 縦横回転、バックグラウンド復帰、音あり・音なし、10分連続プレイを確認する。
7. 実機スクリーンショットと結果を`docs/P8F_EVIDENCE_TEMPLATE.md`形式で記録する。

## 判定規則

- 問題がなければiPhone 17 Proの端末確認をPASS候補とし、他の対象端末へ広げる。
- ゲーム進行、入力、保存、危険予告などに重大な問題があれば、他端末へ広げる前に停止して修正する。
- 軽微な見た目の問題は、再現条件と影響を記録したうえで継続可否を判断する。
- 初見参加者の結果は端末確認と分けて記録し、開発者本人の確認を初見確認へ読み替えない。
- 未実施項目は`NOT TESTED`、環境上実施できない項目は`BLOCKED`とし、PASSへ読み替えない。

## P8-Gへ進む条件

最低でも次を満たすまでP8-Gを完了扱いにしません。

- iPhone 17 ProでP4〜P7の主要操作・進行・保存・復帰を一巡している。
- 重大な入力、進行、保存、画面復帰の不具合が残っていない。
- 実機スクリーンショットを固定版のcommit SHAと結び付けられる。
- 実施した項目と未実施項目を区別した記録がある。

P8-Gでは、その後iPhone 11 Pro、iPad Pro 2018、PCへ対象を広げ、端末別の画面・入力・性能証拠を固定します。
