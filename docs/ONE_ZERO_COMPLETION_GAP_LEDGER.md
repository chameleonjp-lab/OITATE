## 1. 状態の定義

- `DONE`: 実装と必要な証拠がそろっている。
- `VERIFY`: 実装は存在するが、人手受入、初見、実機、最終照合などの証拠が不足している。
- `TODO`: まだ作成・取得・実施していない。
- `DROPPED`: 1.0では意図的に行わない。未完成とは扱わない。

自動CIの成功は、手動受入、初見理解、実機性能、公開品質の代わりにしない。

## 3. すでに完成とみなす項目

### 3.1 ゲームの中心

- 主人公の位置で臆病種を動かす接近圧力。
- 誘導音で追従種を導く。
- 威嚇音で危険種の注意を主人公へ向ける。
- 3種類の専用囲い。
- 危険種の索敵、追跡、狙い、飛びかかり、回復。
- 初回攻撃後の救助、救助期限、再攻撃失敗。
- 安全経路と速い経路。
- 群れ、緊張、混乱、入口予約、後退・再試行。

### 3.2 1.0の内容

- 練習または段階的説明。
- 6ステージ。
- 面ごとの中心概念と完了条件。
- 面4の誘導音→威嚇音の順序条件。
- 面5・面6の動物種別経路条件。
- 進行保存、面別記録、再読み込み復旧。
- 6面クリア後の第4動物候補ゲート。

第4の動物は「条件を満たした場合のみ追加」のため、現時点で通常面へ入れていないことを未完成とは扱わない。

### 3.3 得点・結果・補助

- 100,000点。
- 安全40,000 / 統率25,000 / 危険管理20,000 / 時間15,000。
- S〜C評価。
- 称号と次回助言。
- 標準、補助あり、練習の記録分離。
- 音、振動、操作部品サイズなどの設定基盤。

### 3.4 技術・公開基盤

- Vite / TypeScript / Three.js基盤。
- GitHub Actionsによる型確認、単体、build、ブラウザ試験、公開監査。

## 10. 当面の制作方針

1.0完成までは、新しい動物、新しいステージ、新しい大機能を増やすより、現在の6面を実際に遊んで問題を減らすことを優先する。

直近で実機から複数の不具合が見つかったため、自動試験成功だけで製品品質を十分と判断しない。実機で見つかった不具合は、可能な限り回帰試験へ固定する。
