# P8公開候補版の確認票

この確認票は、P8の公開候補ページと、P7から引き継いだゲーム本体の公開品質を分けて確認する。自動試験だけでは完了にしない。

## 自動確認

- [ ] 候補ページが表示される
- [ ] ページ内リンクが存在する
- [ ] ゲーム開始リンクが`?p7=1`を指す
- [ ] 画像がすべて読み込める
- [ ] 横方向のはみ出しがない
- [ ] `?p7=1`の既存ブラウザ試験が通る
- [ ] 開発時の`?p8-check=1`で診断JSONを保存できる
- [ ] 通常の`?p7=1`では診断操作を表示しない
- [ ] `npm run test:audit`が通る
- [ ] `npm run audit:public`でJSONとMarkdownが生成される
- [ ] CI artifact `p8-public-audit`へ監査結果が保存される
- [ ] `vite preview`のE2Eで要求失敗、4xx/5xx、画像読み込み失敗、console error、page errorがない
- [ ] source head SHAとtested merge SHAが別々に記録される
- [ ] `npm run capture:p8-media`で3場面を再生成でき、CI artifact `p8-gameplay-media`へ保存される

## 候補ページの手動確認

- [ ] ゲームの目的を最初の画面で説明できる
- [ ] 3種類の動物と3つの手段の関係が読める
- [ ] 操作説明を読み、ゲーム開始へ迷わず進める
- [ ] iPhone横画面、iPad、PCで文字とボタンが切れない
- [ ] キーボードだけでリンクを順番に操作できる
- [ ] 音なし、振動なし、補助設定の説明が誤解を生まない
- [ ] 構図イメージ（SVG）と実ゲーム画面（PNG）を誤認しない表示になっている
- [ ] 実ゲーム画面3枚の面・状態・寸法・容量を撮影レポートで確認できる

- [ ] P5手動受入、初見、実機・性能確認
- [ ] P6手動受入、初見、実機・性能確認

- [ ] 15〜30秒の紹介映像
- [ ] 推移依存を含むライセンス一覧

## 判定

P8-Aは候補ページの基盤完成として判定する。上記の公開前未確認事項が残る限り、1.0公開可能、一般公開済みとは判定しない。

P8-Bは開発時測定基盤の完成として判定する。診断JSONの保存成功は、実機・性能・公開品質の確認済みを意味しない。

## P8-Cの確認

P8-Cの自動監査は、公開ビルドの容量、入口ごとの静的な到達ファイル、依存パッケージのライセンス一覧を確認する。監査成功だけでは、実機、画面、音、入力、画像、映像、公開可否を合格にしない。
