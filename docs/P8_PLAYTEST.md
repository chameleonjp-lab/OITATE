# P8公開候補版の確認票

この確認票は、P8の公開候補ページと、P7から引き継いだゲーム本体の公開品質を分けて確認する。自動試験だけでは完了にしない。

## 自動確認

- [ ] 候補ページが表示される
- [ ] ページ内リンクが存在する
- [ ] ゲーム開始リンクが`?p7=1`を指す
- [ ] 画像がすべて読み込める
- [ ] 横方向のはみ出しがない
- [ ] `?p7=1`の既存ブラウザ試験が通る

## 候補ページの手動確認

- [ ] ゲームの目的を最初の画面で説明できる
- [ ] 3種類の動物と3つの手段の関係が読める
- [ ] 操作説明を読み、ゲーム開始へ迷わず進める
- [ ] iPhone横画面、iPad、PCで文字とボタンが切れない
- [ ] キーボードだけでリンクを順番に操作できる
- [ ] 音なし、振動なし、補助設定の説明が誤解を生まない
- [ ] 自作SVGを実ゲーム画面と誤認しない表示になっている
