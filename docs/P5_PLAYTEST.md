# P5 縦切り統合版 プレイテスト

## 対象ビルド

- URL：`?p5=1`
- 目的：3種類の違いと、地形による安全・速い経路の違いを一つの画面で確認する。
- 対象外：正式得点、称号、完成素材、複数ステージ、公開品質。
- 進行判断：P4手動受入は未確認のまま、ユーザー承認によりP5を実装する。

## 初見テスト

長文のルール説明を先に読ませず、最初の12分を観察する。

1. 3種類の動物が何に反応するかを説明できるか。
2. 浅い水と狭い橋の違いを発見できるか。
3. 安全な経路と速い経路を両方試すか、利用できるか。
4. 危険種の狙いと救助の意味を理解できるか。
5. 失敗後に次の試行で変える行動を一つ言えるか。

## 自動回帰

- `npm run typecheck`
- `npm test`
- `npm run build`
- `npm run e2e`
- 3種類11体の固定IDを確認する。
- 水場と狭い橋の通行差を確認する。
- 安全・速い経路の発見状態を確認する。
- 危険種の攻撃予告、救助成功、救助失敗を確認する。
- 11体の収容、結果画面、再挑戦を実ブラウザ経路で確認する。

自動検査の合格は、初見5〜8人の手動受入、P4手動受入、iPhone実機確認の合格を意味しない。
