# P3 最初に遊べる版 正式仕様

- 文書版：1.0
- 文書状態：P3実装候補の正式な範囲・数値・受入条件
- 上位計画：`docs/PRODUCER_MASTER_PLAN.md`のP3
- 対応契約：`docs/P3_IMPLEMENTATION_CONTRACT.md`

## 1. 目的と範囲

P3は、P2の接近圧力を六体の群れへ拡張し、群れのまとまり、緊張、混乱、入口の一体予約、詰まりからの復帰を、最初に一通り遊べる形で確認する。

含めるものは次の通り。

- 臆病種6体、安定ID `coward-1`〜`coward-6`。
- 群れ状態 `cohesive`、`stretched`、`split`。
- 個体の緊張状態 `calm`、`alert`、`confused`。
- 主人公の位置による圧力、予備反応、逃走、歩行・走行差。
- 一つの入口に対する一体予約、後続の待機、予約解除後の再調整。
- 2秒の進展監視、後退、再び列へ戻る詰まり復帰。
- 全身収容、即時再挑戦。

得点、危険種、追従種、救助、Navmesh、完成素材、音作り、公開品質はP3の対象外とする。

## 2. 状態と数値

基準値は`src/game/p3-cowardly-simulation.ts`の`P3_TUNING`と一致させる。

| 項目 | 正式値 |
|---|---:|
| 個体数 | 6体 |
| 判断更新 | 20Hz（0.05秒） |
| 注意・誘導・緊迫距離 | P2の5.5m / 3.5m / 1.5m |
| 予備反応 | 0.45秒 |
| 歩行時の逃走速度 | 0.9m/s |
| 走行時の圧力倍率 | 1.35 |
| 入口待機の上限 | 2秒 |
| 後退時間 | 0.85秒 |
| 入口進入の詰まり監視 | 2秒 |
| 入口進入速度 | 2.2m/s |
| 収容確定保持 | 0.35秒 |
| 動物間最低距離 | 1.15m |
| 群れの伸長判定 | spread 3.2m以上 |
| 群れの分裂判定 | spread 4.5m以上を1秒 |
| 分裂からの回復判定 | spread 3.6m以下 |
| 混乱の最低継続 | 1.5秒 |
| 緊張のalert遷移 | 45以上、解除30以下 |
| 緊張のconfused遷移 | alert中に85以上、解除55以下かつ最低時間後 |

P3の`confused`は、上位の状態遷移仕様にある最低継続付きの強い緊張状態を、この試作で画面に表示する実装名である。混乱中も柵回避、入口通行禁止、最低距離を無効化しない。

## 3. 入口予約と復帰

- 一つの入口の予約所有者は常に一体以下とする。
- 予約所有者が入口の喉へ進入したら`enteringPen`へ移り、後続は入口手前で`waitingForEntrance`となる。
- 待機中は2秒を上限とし、上限到達時に`backingOff`へ移る。
- `backingOff`は0.85秒後に`fleeing`へ戻り、再び入口候補になれる。
- 進入動作が2秒経過しても全身収容できなければ後退へ移り、復帰回数を記録する。進入前の逃走中に2秒間ほとんど距離が進まない個体も、入口以外では後退へ移る。
- 収容済み個体は予約、群れのspread、圧力、間隔処理から除外する。

## 4. 受入条件

P3の制作上の受入条件は、正しい位置取りで5回中5回クリアできる再現性、技術的な詰まりによる失敗が20回中1回以下、混乱の主原因をプレイ後に説明できること、歩行と走行の使い分けが結果に表れることである。

自動検査は状態遷移、単一予約、待機・復帰、全身収容、有限値、既存P1/P2回帰を確認する。自動検査の成功は、初見プレイ、5回再現性、混乱原因の説明、実機性能の合格を意味しない。

## 5. 変更境界

P3の受入条件、状態名、閾値、タイマー、個体数を変更する場合は、本書と`docs/P3_IMPLEMENTATION_CONTRACT.md`を同じ作業単位で更新する。追従種、危険種、得点をこの作業へ追加しない。
