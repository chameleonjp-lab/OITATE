# P4 危険検証版 プレイテスト

## 対象ビルド

- URL：`?p4=1`
- 目的：危険種を主人公へ引きつけ、専用囲いへ隔離する順序と、攻撃後の救助を確認する。
- 対象外：P3の手動受入、追従種との統合、11体統合、得点、実機性能の合格。
- 作成時点：P3手動受入はユーザー承認により未確認のままP4へ進行。

## 初見テスト

5人以上を目安に、長文のルール説明を先に読ませず、次を観察する。

1. 危険種が狙いを始めたとき、攻撃前に危険を認識できるか。
2. 威嚇音で危険種を主人公へ引きつける目的が分かるか。
3. 主人公が危険種を囲いへ誘導し、自分だけ外へ出る意味が分かるか。
4. 救助待ちの残り時間と、救助できた・できなかった理由を説明できるか。
5. 失敗後に、次の試行で変える行動を一つ言えるか。

## 自動回帰

最低限、次を確認する。

- `npm run typecheck`
- `npm test`
- `npm run build`
- `npm run e2e`
- 危険種の狙いが1.2秒未満で飛びかからない。
- 狙い中の威嚇音で飛びかかりを中断できる。
- 飛びかかり開始後の威嚇音では攻撃を取り消さない。
- 救助成功、期限切れ失敗、専用囲いへの隔離を同じ固定更新規則で再現できる。

P3の5回連続収容、20回中の詰まり率、初見プレイ、P1 iPhone実機、主要端末性能は、P4自動検査の合格とは別に扱う。
