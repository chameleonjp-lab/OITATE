# P6 縦切り完成版 正式仕様

- 文書版：1.0
- 対象：P5の11体・1ステージを、初回説明から結果・再挑戦までつなぐ完成版候補
- 起動：開発確認は `?p6=1`
- 上位計画：`docs/PRODUCER_MASTER_PLAN.md` のP6
- 得点の正式参照先：`docs/GAME_DESIGN_MASTER_PLAN.md` 第15章

## 1. 含める範囲

P6は、新しい動物や2面目を増やさない。P5の決定論シミュレーションと仮形状を使い、次を一つのプレイへ接続する。

- 初回説明：移動、カメラ、臆病種、追従種、危険種の反応を短い操作説明で示す。
- 1ステージ：臆病種6体、追従種4体、危険種1体、3つの囲い、浅い水、橋、2経路。
- 結果画面：総得点、S〜C評価、4項目、称号、次回の助言、再挑戦。
- 設定：音、振動、補助、操作部品の大きさ。
- 端末内記録：標準と補助ありを別々に保存する。
- 仮完成表示：P5の仮モデル、囲い、地形表示を完成版候補の画面で使用する。

## 2. 得点

総得点は100,000点とし、次の4項目へ固定する。

| 項目 | 最大点 | 比率 |
|---|---:|---:|
| 安全 | 40,000 | 40% |
| 統率 | 25,000 | 25% |
| 判断 | 20,000 | 20% |
| 時間 | 15,000 | 15% |

初期値と減点は、ゲームデザイン詳細計画書に合わせる。

- 救助発生：1回10,000点。
- 高緊張の累積：1個体秒50点、合計8,000点を上限とする。
- 危険種への曝露：1秒100点。
- 危険種の狙い開始：1回2,000点。
- 時間の目標：300秒。600秒で時間評価3,000点まで下がる。
- 間違った囲いへの確定はP5の状態上成立しないため、統率の基本点と種類別収容で評価する。

評価は、クリア時だけS〜Cを確定する。失敗時は「未クリア」とし、記録へ保存しない。

- S：90,000点以上、救助なし。
- A：75,000点以上。
- B：60,000点以上。
- C：クリア。

## 3. 初回説明と設定

初回説明は長い説明文を読ませず、次の順序を示す。

1. 左側で主人公を動かし、右側でカメラを動かす。
2. 臆病種の後ろへ回り、接近で動かす。
3. 追従種へ誘導音を使う。
4. 危険種が狙ったら威嚇音を使う。

説明はスキップでき、二回目以降は端末内記録で短縮できる。

補助ありでは、危険種の狙い中だけ判断の進行を70%へ下げる。補助ありの結果は標準記録と混ぜない。音、振動、操作部品の大きさは標準記録で変更できる。

## 4. 保存と安全境界

- 保存先はブラウザの端末内保存だけとする。
- アカウント、通信、オンラインランキング、個人名、端末固有識別子は追加しない。
- 記録キーはP6専用とし、標準・補助ありを別の項目へ保存する。
- 保存に失敗してもプレイ自体は続行する。
- 開発用E2E機能は `import.meta.env.DEV` と `?p6-e2e=1` の両方が必要で、本番成果物へ公開しない。

## 5. P5との互換境界

- `?p5=1` は従来どおり仮結果画面を使う。
- `?p6=1` だけがP6の説明、設定、得点、記録画面を使う。
- P3、P4、P5の公開APIとE2Eフックを変更しない。
- P5の11体、固定更新20Hz、柵判定、救助、経路判定の規則をP6側で上書きしない。
