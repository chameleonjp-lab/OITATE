# P3 最初に遊べる版 プレイテスト

この手順は、六体の群れを位置取りで導き、入口の順番と混乱からの復帰を理解できるかを確認する。自動テストの成功で初見プレイの判定を置き換えない。

## 対象ビルド

- 横画面のブラウザ版。
- 仮素材の臆病種6体と囲い1つ。
- 主人公の移動とカメラはP1の入力方式を使用する。
- P1回帰用の合図ボタンは通常画面で隠れ、P3の動物へ効果を与えない。
- 入口予約は一体ずつ、待機上限は2秒、詰まり後は後退して再調整する。
- 六体を全身収容すると完了し、「もう一度試す」で初期状態へ戻る。

## 初見テスト

1. 横画面で読み込み、説明を追加せず10秒観察してもらう。
2. 120秒以内に、移動とカメラだけで群れを囲い方向へ導いてもらう。
3. 入口で待つ個体、後退する個体、混乱表示が出た個体を記録する。
4. クリア後に「なぜ混乱したと思うか」「歩行と走行をどう使い分けたか」を尋ねる。
5. 5回の再現試行では、正しい位置取りの手順を同じテスターに説明してから、毎回初期状態で実施する。
