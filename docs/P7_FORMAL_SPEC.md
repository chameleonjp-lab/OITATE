# P7「1.0内容完成」正式仕様

## 目的

P7は、P5の縦切りシミュレーションを土台に、初回プレイヤーが練習から総合面まで段階的に学べる1.0内容を実装する。公開ページ、運用、権利確認はP8以降の責務とし、このP7ではゲーム内の6面進行と記録保存を完成させる。

## 起動と範囲

- 起動 URL は `?p7=1`。
- P5/P6 の既存 URL と通常起動の挙動は変更しない。
- アカウント、サーバー同期、外部ネットワークは追加しない。
- 進行は `localStorage` の `oitate:p7:progress:v1` に保存する。
- 進行は同一ブラウザ内のプレイヤー向けであり、保存領域が使えない場合もプレイ自体は継続できる。

## 面構成

| 面 | 中心概念 | 内容上の条件 |
| --- | --- | --- |
| 練習 | 安全な操作 | 臆病種2体を収容。参考記録として保存 |
| 1 接近圧力 | 位置取り | 臆病種6体を収容 |
| 2 誘導音と経路 | 合図と地形 | 追従種4体、誘導音、速い経路の発見 |
| 3 危険管理 | 危険種の隔離 | 臆病種1体と危険種1体、威嚇音 |
| 4 合図の副作用 | 合図の相手を選ぶ | 臆病種3体、追従種3体、危険種1体。2種類の合図 |
| 5 群れの分裂 | 経路の順番 | 臆病種6体、追従種4体。安全・速い2経路 |
| 6 総合 | 複合判断 | 3種類11体、2経路、2種類の合図 |

練習面を除く6面は、各面をクリアすると次の面を解放する。完了判定は収容数だけでなく、その面に定義された経路の発見とイベントの発生も確認するため、見た目だけの配置変更ではクリアできない。

## 記録と評価

- 各面は標準、補助あり、練習を別記録として保持する。
- 記録項目は最高得点、評価、最短時間、試行回数。
- 評価はP6の安全・連携・判断・時間のスコア計算を共通利用する。
- リロード後も進行と記録を復元する。
- 破損した保存値は初期状態へフォールバックし、プレイを止めない。

## 第4の動物

6面すべてのクリア後に `fourthAnimalGate = eligible` を保存し、検証候補として表示する。ただし、P4・P5・P6の手動受入、初見テスト、実機・性能確認が未確認のため、第4の動物は通常の1.0面には追加しない。第4の動物の追加は、別途受入確認と明示承認を経た後の作業とする。

## 受入前提と残リスク

このブランチでは、P4・P5・P6の手動受入、初見テスト、実機・性能確認を未確認のまま扱う。P7の自動テストが通過しても、これらの確認済みを意味しない。既存縦切りの手戻りが発生した場合は、P7の面構成、記録形式、UIを再調整する。
